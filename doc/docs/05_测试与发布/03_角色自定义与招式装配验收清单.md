# 角色自定义与招式装配验收清单

## 外观

- [ ] 所有合法部件组合可实例化；
- [ ] 不改变 hitbox、hurtbox、pushbox 或移动参数；
- [ ] 左右朝向、基础动作、受击、倒地和 KO 无明显穿层；
- [ ] 背景相似色和高频特效受到限制；
- [ ] 缺失部件可降级并明确提示。

## 招式装配

- [ ] 槽位、预算、种族限制、互斥和依赖正确；
- [ ] 输入冲突被禁止或有确定优先级；
- [ ] 招式包包含状态、动画、hitbox、attribute 和反馈引用；
- [ ] 非法装配不能开始比赛；
- [ ] 内容更新后旧预设可迁移、降级或明确拒绝。

## 存档

- [ ] 原子保存和备份恢复；
- [ ] schema 版本迁移；
- [ ] 稳定内容 ID 而非脆弱节点引用；
- [ ] 损坏数据不会导致启动崩溃。
