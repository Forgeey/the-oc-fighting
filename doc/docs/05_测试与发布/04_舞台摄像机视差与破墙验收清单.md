# 舞台、摄像机、视差与破墙验收清单

- [ ] 地面、墙、出生点和战斗边界正确；
- [ ] 双角色在合法区域内保持可见；
- [ ] 视差无接缝、跳变或明显漂移；
- [ ] 前景不遮挡角色、判定和 HUD；
- [ ] 动态/装饰层可关闭且不影响规则；
- [ ] 空中连段和角落摄像机稳定；
- [ ] 震动、闪光和背景动态可减弱/关闭；
- [ ] 破墙同一事件只触发一次；
- [ ] 过场期间输入、hitbox 和比赛计时符合设计；
- [ ] 新段落重定位、朝向、资源、连段和状态正确；
- [ ] KO、双 KO、超时与破墙冲突有确定结果；
- [ ] 资源失败有安全降级；
- [ ] 目标设备稳定 60 FPS。
