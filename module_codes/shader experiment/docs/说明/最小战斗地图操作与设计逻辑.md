# 当前战斗地图：运行、节点与配置

> 更新：2026-11-14。内部画布1280×720，方案B为默认。

## 运行

F5进入 `scenes/battle_map_reference.tscn`；右上按钮在 **Reference ↔ Nearest** 两个场景之间切换并保留相机状态。

- Reference：wall1矩形正面、wall2预绘侧面，参考四角相对映射。
- Nearest：旧floor.png墙面、普通面UV；用来保留原方案比较，不代表同素材的单变量实验。
- A/D：相机左右。W/S：改变真实高度。按键不改Z。
- R：恢复该场景启动时的相机地面位置与高度。

当前输出与窗口均1280×720，初始1:1。更大的窗口仍保持比例、整数放大并留边，最小窗口1280×720。当前不实现小于此尺寸的缩小显示或任意窗口分辨率直接绘制。

## 节点

```text
BattleMap
├─ MapCamera
├─ Floor（ColorRect）
├─ Buildings
│  ├─ LeftTall
│  ├─ LeftFront
│  └─ Right
├─ Players
│  ├─ Player1（右侧）
│  └─ Player2（左侧，flip_h=true）
└─ ComparisonUI（CanvasLayer）
   └─ SwitchScene
```

Reference建筑挂reference_building.gd，继承building.gd；两名角色仍为AnimatedSprite2D。没有新增离屏视口、全局参数或共享Shader文件。

## 当前参数

| 参数 | 当前值 |
| --- | --- |
| 内部渲染 / 初始窗口 | 1280×720 / 1280×720 |
| 相机位置X/Z、高度 | (0,-1400)、210 |
| 焦距 | 约933.3333渲染像素 |
| 地平线Horizon | 460渲染像素 |

| 玩家World Units Per Texel | 3，世界体量标尺 |
| 当前精灵显示缩放 | 约2，不再要求源像素与输出像素1:1 |

相机高度与世界尺度没有跟着画布加倍；焦距、地平线和CPU/Shader视口一致换算。人物在同一个物理窗口中的大小与之前基本相同，地图实际采样却细了一倍。

## 参数入口

- MapCamera：Ground Position / Height / Focal Length / Horizon / Speed。
- 玩家：Ground Position / Jump Height / World Units Per Texel。Transform Position/Scale每帧覆盖。
- 建筑：Ground Position / World Size；Reference另有Side Reference Corners。
- Floor材质：Ground Texture / Ground Min/Max / Tile Size / Guide Z / Show Guide。
- Reference建筑材质：Front/Side Texture / Tint / Side Brightness。

CameraRuntime、box_min/box_size和side_reference_map是运行输出，不手动配置。没有@tool，停止运行时不会实时投影；即时调参请修改Remote实例。

## 动画与几何

idle.png仍按17个400×270区域切帧，循环10FPS。offset=(0,-61)对齐实际脚底，透明画布不当成角色大小。脚点取整仍保留，取整现在落在更细的输出网格，不影响玩法坐标。

三栋建筑仍只画正面和可见侧面；不补屋顶或背面。z_index=-int(世界Z)是整对象排序，不是深度缓冲。世界Ground Position.y代表Z，不能用它当高度。

## 辅助线

Show Guide开关、Guide Z为世界深度；默认0，线经过双方脚点。原-150只是历史观察位置，可任意改为地面范围内的值。Guide Half Width是世界半宽，不是屏幕像素宽。

Horizon只改竖直构图，Height改实际观察高度；改焦距或相机Z会同时改变物体大小。
