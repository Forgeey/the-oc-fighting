# Shader实验文档入口

> 更新：2026-11-14。默认Reference方案B，当前内部画布1280×720。

## 当前方向

预绘参考视角的像素素材 + 原有伪3D空间 + 参考四边形相对映射。

不要求所有源纹素代表相同世界尺寸，也不要求不同深度颗粒绝对等大。当前屏幕规格由渲染与构图实验决定，**不再根据角色源像素尺寸反推屏幕高度、宽度或目标角色占比**。

当前将内部画布由640×360提高到1280×720，窗口仍为1280×720；焦距与地平线同比换算，世界几何与相机世界位置不动。这是真正增加输出采样数，不是放大旧低清结果。

## 地图美术制作入口

制作正式地图先读：[格斗地图Aseprite分层绘制与交付规范](方案/格斗地图Aseprite分层绘制与交付规范.md)。

推荐“统一参考机位总图 → 两个角色参考层 → 建筑分面/景深分层 → 隐藏正面补画side后恢复合成 → 分层导出和坐标/深度清单 → 游戏内极限机位验收”。

母稿顺序可以约定为前后/深度顺序，但精确Z、坐标和面类型需随资源清单保存。side可以留在同一工程中隐藏/补画，镜像复用需美术允许；仅要求它自己的参考四边形有面积，不强制每次制作辅助相机截图。代码再根据分层图片与清单构建地图，当前仍手动接入。

定位交付必须包含母稿画布尺寸、目标层/帧的上下左右像素距离、实际导出裁切框，以及脚点/四角转换；见制作规范第9.1.1～9.1.3节。代码先按这些信息回贴母稿核对，再接入世界深度，避免丢失PNG位置。

1. `说明/最小战斗地图操作与设计逻辑.md`：两个场景、按键与当前参数。
2. `说明/渲染分辨率与闪动对照说明.md`：本轮调整、旧低清与新原生截图、效果边界。
3. `说明/参考视角侧面方案B制作与使用说明.md`：wall1/wall2、参考四角和素材使用。
4. `说明/伪3D空间假设、参数与计算说明.md`：相机、几何、源素材世界体量与参考映射。
5. `计划/横版像素格斗地图伪3D像素稳定性研究计划.md`：当前待验证事项，不再沿用角色尺寸决定分辨率的流程。
6. `说明/相机参数唯一入口与高度调整说明.md`、`计划/战斗地图Shader实验计划与入门指南.md`：参数入口和代码入门。
