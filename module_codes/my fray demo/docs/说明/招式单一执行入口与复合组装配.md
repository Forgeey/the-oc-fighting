# 招式单一执行入口与复合组装配

> 2026-11-11 当前接口：Move.state 单段引用 FighterStateDefinition，多段引用 FighterCompoundStateDefinition。组直接持有 states／transitions；叶子与转换不保存父组字符串。没有兼容别名或按目录推导组。

## 1. Move 不再重复列依赖

旧 state_ids 数组已删除。单段 Move 只引用一个叶子，多段 Move 只引用一个复合定义。组内默认入口由 start_state 指定，成员由组的 states 指定，连接由组的 transitions 指定；不让数组首项充当另一套入口。

~~~gdscript
@export_custom(PROPERTY_HINT_RESOURCE_TYPE,
    "FighterStateDefinition,FighterCompoundStateDefinition")
var state: Resource
~~~

这是静态资源引用，不保存运行计时或当前角色。运行叶子由 Builder 创建；实际组仍为原生 FrayCompoundState，不新增 FighterCompoundState 运行包装。

## 2. Inspector 中的最小配置

单段轻攻击：Move.state 指向 resource/states/light_attack_state.tres，直接位于根，不套额外组。

多段组合技：

~~~text
组定义 combo1：
  state_name = combo1
  start_state = B
  states = [B定义, C定义, D定义]
  transitions = [B→C, C→D]
多段 Move：
  state = combo1组定义
~~~

组内叶子仍需登记到 StateLibrary.states，组登记到 StateLibrary.compound_states。Loadout 使用角色提供的权威库解析叶子 ID 和组名；同名／同 ID 的嵌入定义不覆盖库内脚本、动画、判定或入口。

选择该组会装配全部成员，但不自动装备子招式或其命令。没有反向成员查询：直接引用 C 的 Move 将 C 装配到根，不会因此猜出 combo1。

## 3. 同一静态定义可放在多个容器

同一个 B 定义可同时用于 root/B、combo1/B、combo2/B；各自运行实例、计时和父对象独立。各组的内部规则即使引用同一静态规则资源，也分别注册和查询自己的本地条件。

根的选择由 selected_state_names 与叶子 Move.state 决定；组的成员由复合定义.states 决定。selection.root_states 记录根放置，selection.states 仅是静态依赖去重并集，供 HitStateBuilder 使用。不能将并集再次全部挂在根。

## 4. 根边与内部边

~~~text
TransitionLibrary.transitions：
  idle→A
  A→combo1
  A→idle
  combo1→idle
combo1.transitions：
  B→C
  C→D
~~~

归属由存放位置唯一确定。转换自己只保存直接 from/to 名称和规则条件，不保存 owner 字符串；Builder 也不从端点或名称猜 owner。各容器只绑定自己规则所需条件，不继承根条件。

Move.state 不是直接 goto：一次命令仍可被多条边接受，当前活动状态和 Fray 条件决定能否发动。Move.prereqs 合并到匹配目标的入口边私有副本，不能写回共享定义或扩散到全部内部转换。

## 5. A 同根、B/C/D 在组的例子

~~~text
root
├─ idle
├─ A ← 单段 Move.state
└─ combo1 ← 多段 Move.state
   ├─ B ← start_state
   ├─ C
   └─ D
~~~

选择 combo1 不会自动装配根 A；A 需通过它自己的 Move 或根基础选择装配。A→combo1 由下一次合法后续命令触发，进入 B，不重播 A。

B/C/D 都可自然收招。组不设 end_state；父 combo1→idle 使用 auto_advance=true、AT_END，插件递归等待当前攻击完成。不增加 done，也不重复添加游戏层完成条件。

A／AB／ABC／ABCD 的展示与装备授权仍是另一层业务；装配了整组不表示已实现每条路线独立授权。未来局部 pending 与连接权限不由成员数组自动产生。

## 6. 当前支持边界与验证

支持根下的一层局部组。states 是叶子定义数组；不在本轮加入任意深度容器或内容合法性预检。内容作者保证 ID、名字、start_state 与成员／端点有效。

专项测试覆盖：单个组 Move 选入所有成员、根叶子不自动选组、根／两组复用同一静态定义时实例独立、内部规则和条件不泄漏、A／AB／ABC／ABCD、单一真实按键连续接段、编辑器和新运行进程保存重载。

场景节点与 Fray 插件本轮不变。运行器为 tests/movement/run_headless.py，可使用 compound、resources、lifecycle 等 suite。
