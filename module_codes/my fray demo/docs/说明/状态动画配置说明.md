# 状态动画配置说明

> 2026-11-11 容器式装配更新：叶子和转换不再保存父组字符串；FighterCompoundStateDefinition.states／transitions 直接持有成员与内部边，TransitionLibrary.transitions 仅持有根边。组内归属由资源放在哪个容器决定，详见[状态机资源配置说明](状态机资源配置说明.md)。旧字段说明及示例已删除，不提供兼容别名。


> 2026-11-11：动作脚本与定义已移至平铺职责目录，没有状态分类字段。所有状态进入时仍由 FighterState 统一播放 animation_key，动画键必填；自定义外观映射尚未实现。

## 1. 唯一配置来源

| 层 | 职责 |
| --- | --- |
| FighterStateDefinition | state_id、state_name、state_script、animation_key、hit_state_definition；运行父对象不保存在此处 |
| FighterMoveDefinition | 身份、显示名、command、state（单段／复合组静态引用）、条件；不保存动画键或动作帧数 |
| FighterState 实例 | 持有只读定义，进入时选姿态和播动画，退出时清姿态 |
| BasicAttackState | 读取当前姿态攻击 Attribute 的帧窗口，不依赖 args.move |
| Fighter／表现层 | 解析动画语义并调用 AnimatedSprite2D.play()；当前解析原样返回 |

每个状态必须配置存在于 SpriteFrames 的 animation_key。没有空键跳过、Move 覆盖或备用动画；未制作动画时由内容作者配置有效占位资源。

## 2. 当前默认资源

| 动作名 | 状态定义 | animation_key | 执行脚本（相对 scripts/states/fighterstates/） |
| --- | --- | --- | --- |
| idle | resource/states/idle_state.tres | idle | idle_state.gd |
| fwalk | resource/states/fwalk_state.tres | fwalk | fwalk_state.gd |
| bwalk | resource/states/bwalk_state.tres | bwalk | bwalk_state.gd |
| crouch | resource/states/crouch_state.tres | crouch | crouch_state.gd |
| light_attack | resource/states/light_attack_state.tres | light_attack | basic_attack_state.gd |

动画键不从动作名、ID、文件路径自动派生。移动资源不改键，不改变状态 ID 或动作时序。

## 3. 构建与执行

~~~text
Loadout 解析选择
→ Builder 创建叶子并绑定 state_definition
→ Fray 初始化与转换进入叶子
→ FighterState._enter_impl 选择判定姿态并请求动画
→ Fighter.play_animation
→ _resolve_animation_key（当前原样返回）
→ AnimatedSprite2D.play
~~~

具体叶子覆盖进入时调用 super(args)，不要再重复播放一次。BasicAttackState 的完成来自逻辑帧与攻击 Attribute，不依赖 animation_finished，也不从 Move 取帧数。

局部组的 B/C/D 仍是各自的普通叶子，进入新段时请求自己的姿态和动画；原生父组不播放一套重复的动作动画。

## 4. 共享与扩展边界

静态定义可以共享，不保存角色引用、计时或当前播放状态；运行对象独立。角色定制应使用专用定义或战前显式复制后配置，不能在运行时修改公共库影响其他角色。

当前仅保留 _resolve_animation_key 入口，没有动画映射 Resource、皮肤槽位编辑器、运行时热更新或自动回退素材。未来外观映射不能自动改变判定框或攻击时序。
