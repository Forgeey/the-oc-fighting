# 状态动画配置说明

> 修订日期：2026-10-27。基本状态和招式状态统一读取 StateDefinition.animation_key。自定义动画只预留解析入口，不表示已完成外观映射、运行时换装或部件动画系统。

## 1. 唯一配置来源

| 层 | 当前职责 |
|---|---|
| FighterMoveDefinition | 招式身份/显示名、command、入口/状态依赖、条件及起手/有效/恢复帧数；不保存 animation_key |
| FighterStateDefinition | group_path、state_name、state_script、animation_key 及实际判定定义 hit_state_definition |
| FighterState 运行实例 | 持有 Builder 绑定的 state_definition 只读引用，保存该实例的运行进度 |
| 具体状态脚本 | 决定何时调用 play_state_animation()，基类不在进入时自动播放 |
| Fighter / 表现层 | 接收动画语义，预留解析入口并提交 AnimatedSprite2D.play() |

同一个动画语义只在状态定义保存一次，不使用 Move 覆盖 State 或空值回退规则。空 animation_key 表示该状态不请求播放，当前显示保持原状；它不隐式表示停止/隐藏。其他状态配置及 SpriteFrames 资源仍由内容作者保证有效。

## 2. 默认资源

在 resource/state_machine/state_library.tres 中配置：

| 状态路径 | animation_key | 脚本相对 fighterstates/ 的路径 |
|---|---|---|
| neutral/idle | idle | neutral/idle_state.gd |
| neutral/fwalk | fwalk | neutral/fwalk_state.gd |
| neutral/bwalk | bwalk | neutral/bwalk_state.gd |
| neutral/crouch | crouch | neutral/crouch_state.gd |
| action/basic_attack/light_attack | light_attack | action/basic_attack/basic_attack_state.gd |

动画键不是 state_name、move_id 或显示名称的自动派生值，允许独立配置。基本状态更换动画不必修改脚本；具体动画必须存在于当前 SpriteFrames 中，因为自定义映射尚未实现。

## 3. 构建与执行

```text
Loadout 选择 + Move.required_state_paths
    ↓
Builder 实例化状态并绑定 state.state_definition
    ↓
状态初始化或转换进入，叶子在正确时机调用 play_state_animation()
    ↓
读取该实例 state_definition.animation_key
    ↓
Fighter.play_animation(key)
    ↓
Fighter._resolve_animation_key(key)  # 当前直接 return key
    ↓
AnimatedSprite2D.play(key)
```

绑定发生在状态机 initialize() 之前，所以真实初始入口、普通转换、external 招式转换及重新进入都能读取定义，不要求每条边传动画参数。BasicAttackState 仍从 args.move 获取本次招式和帧数，不因迁移动画字段而改变完成模式或逻辑帧。

定义是共享静态配置，不写入角色引用、计时或运行实例；多个角色的状态实例独立。若生成前要给一个角色不同的配置，应提供其专用定义/库或显式复制后配置，不在运行时改共享库。当前没有实现热更新协议：修改键后不会自动重播，也不会重建状态机。

## 4. 自定义动画的预留边界

目前只保留 _resolve_animation_key() 统一接入点，不新增动画映射资源、字典、皮肤类型、编辑器或回退素材。未来可在此解析“状态语义 → 当前角色实际动画”，无需逐个修改状态脚本；本次测试只验证入口存在且原样返回。

将来角色换外观不应修改公共状态定义来影响所有角色，也不能让动画素材决定攻击完成或判定窗口。当前 AnimatedSprite2D 自主播放，战斗阶段仍由逻辑帧推进，不依赖 animation_finished。

## 5. 分组目录与复用

```text
scripts/states/fighterstates/
├─ fighter_state.gd
├─ neutral/
│  ├─ idle_state.gd
│  ├─ fwalk_state.gd
│  ├─ bwalk_state.gd
│  └─ crouch_state.gd
├─ action/
│  ├─ basic_attack/
│  │  └─ basic_attack_state.gd
│  ├─ special_attack/    # .gitkeep 预留
│  ├─ composite_attack/  # .gitkeep 预留
│  └─ throw/             # .gitkeep 预留
└─ reaction/            # .gitkeep 预留
```

五个迁移脚本的 .gd.uid 保留；基类无所属业务组，留在根部。不新增尚无业务的空脚本类。文件目录仅用于归档，状态层级仍由 StateDefinition.group_path 决定，同一脚本可以被不同状态定义复用并播放各自动画。

## 6. 回归入口

```powershell
python tests/neutral/run_headless.py --godot <Godot控制台程序路径> --suite resources
python tests/neutral/run_headless.py --godot <Godot控制台程序路径> --suite moves
```

资源套件覆盖初始入口动画、四个基本状态按配置播放、external 攻击读取状态动画、Move 不再持有动画字段、空键跳过播放、共享库不被角色私有配置污染以及同脚本不同实例绑定不同定义。自定义映射尚未实现，不把测试中的私有 SpriteFrames/定义副本当作完整外观装配功能。

当前基础攻击执行类为 BasicAttackState，文件 basic_attack_state.gd，改名保留 UID；脚本名变化不影响状态路径、状态动画配置或动作逻辑帧。

判定姿态已由状态定义绑定，进入/退出使用 FighterState 的公共协议；具体状态的进入回调需先调用 super(args)，CrouchState 的退出需调用 super() 后恢复世界碰撞体。动画仍由具体脚本调用 play_state_animation()，不与判定自动播放混为一谈。
