## 4. 原生转换与组出口

普通边、命令边都编译为原生转换，条件在 owner 本地注册。输入边先注册，之后是普通边；各类按 priority 小者优先，同值按资源顺序。

命令边运行对象启用 auto_advance，以执行 Fray 的 advance_conditions 检查；输入 accepts 仍必须匹配 sequence，不会空输入自动攻击。

局部组不设置唯一 end_state，不增加 done。combo1→idle 在父级配置 AT_END，完成判断由已修复的插件递归传播；不再配置 active_leaf_done 前置条件；完成只是许可，仍需要出口边与 advance。组内合法即时接续优先于父级收招。
